# claude_01

"Hello, World"를 출력하는 단일 HTML 페이지 프로젝트입니다.

## 사용법

1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저로 엽니다.
   - 파일을 더블클릭하거나, 브라우저 주소창에 `file:///경로/index.html`을 입력합니다.
3. 화면 중앙에 "Hello, World" 문구가 표시됩니다.

별도의 설치나 빌드 과정 없이 정적 HTML 파일만으로 동작합니다.

### 로컬 서버로 실행 (선택)

브라우저 보안 정책 등으로 파일을 직접 열기 어렵다면 간단한 로컬 서버를 사용할 수 있습니다.

```bash
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 파일 구성

- `index.html` — "Hello, World" 문구를 표시하는 페이지. 시스템의 다크/라이트 모드 설정에 맞춰 배경과 글자 색이 자동으로 전환됩니다.
